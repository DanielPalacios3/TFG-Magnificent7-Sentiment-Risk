# Dataset ilustrativo – TFG

Este repositorio contiene el dataset ilustrativo utilizado en el anteproyecto del Trabajo Fin de Grado
"Predicción del riesgo de mercado en las Magnificent 7 con modelos GARCH-X y XGBoost usando sentimiento
de noticias y redes sociales".

## Contenido
- `dataset_ilustrativo_M7_AAPL.csv`: precios diarios reales de Apple (OHLC y volumen) descargados de Stooq,
  con variables derivadas de rendimientos, volatilidad y medidas de sentimiento con carácter ilustrativo.

## Nota
Las variables de sentimiento incluidas tienen carácter ilustrativo y se emplean exclusivamente para
mostrar la estructura del conjunto de datos y la integración con información de mercado.
